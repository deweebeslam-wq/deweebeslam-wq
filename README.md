### 🛠️ I-TOOLS for Revit

A suite of **40+ Revit add-in tools** in one ribbon tab, used in production at I-BIMS.

| Area | Tools |
|---|---|
| **Coordination & clash** | Smart Clash Manager (Navisworks reports, BCF 2.1) · Clash Test Pro · MEP Opening Generator · Copy From Link |
| **Model quality** | Model Health Analyzer with interactive dashboard & 3D web viewer · Warning Explorer · Smart Purge · Compare Files |
| **Data** | Data Manager (schedules ↔ Excel, shared parameters, bulk edits) · Renumber Pro · Parameters Add · Element Coder |
| **Documentation** | Batch Export (PDF / DWG in shared coordinates / NWC / IFC) · Sheet Generator · Sheet Organizer · Tag All · Quick Dimension |
| **Modelling** | Room Manager · Smart Repeat · Create Levels / Types · Lintels · Fireproofing · Join / Unjoin |

- Supports **Revit 2022 – 2027** from two builds (.NET Framework 4.8 and .NET 8)
- **Auto-updates** from GitHub Releases with SHA-256 verification — installs while Revit stays open
- 📦 Latest release: **[I-TOOLS-Releases](https://github.com/deweebeslam-wq/I-TOOLS-Releases/releases/latest)**
